// features

Built for production from day one

No toy wrappers. Every layer is a real implementation.

⚡

Multi-provider routing

Requests route through a configurable fallback chain — OpenAI fails, Anthropic takes over automatically. Zero client changes needed.

🔒

Dual auth — API keys + JWT

bcrypt-hashed API keys with prefix lookup or HS256 JWTs with 15-minute expiry. Both live behind the same middleware path.

🧠

Semantic cache

SHA-256 content-addressed cache in Redis eliminates duplicate LLM calls for identical payloads. Cache hits never touch a provider.

🚦

Token bucket rate limiting

Per-tenant Redis-backed rate limiter using atomic operations. Configurable burst + refill rate per tenant at runtime.

📊

Full observability

Prometheus counters, histograms, and gauges wired to every path. Grafana dashboards provisioned automatically via config.

☸️

Production infra included

Modular Terraform for EKS, RDS Multi-AZ, and ElastiCache. Helm chart with HPA, PodDisruptionBudget, and secrets management.
