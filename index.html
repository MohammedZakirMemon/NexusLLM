// capabilities

Every layer is real

No mock implementations. Each component is production-wired.

Routing

Fallback chain routing

OpenAI fails → Anthropic takes over automatically. Configurable provider order with per-provider timeouts.

Auth

Dual auth layer

bcrypt-hashed API keys with prefix lookup, or HS256 JWTs with 15-minute expiry — same middleware path.

Cache

Semantic cache

SHA-256 content-addressed Redis cache eliminates duplicate LLM calls. Cache hits never reach a provider.

Rate limiting

Token bucket limiter

Per-tenant Redis atomic token bucket. Configurable burst + refill rate. Stays consistent under concurrent load.

Observability

Prometheus + Grafana

Counters, histograms, and gauges on every path. Grafana dashboards provisioned automatically via config.

Infra

Full IaC included

Modular Terraform for EKS, RDS Multi-AZ, and ElastiCache. Helm + HPA + PodDisruptionBudget. 4-stage CI/CD.
